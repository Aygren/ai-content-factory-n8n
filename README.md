# 🤖 Автономный ИИ-Контент-Завод на n8n & Supabase

Полноценная production-ready система автоматизации контент-маркетинга с интеграцией ИИ-агентов (Multi-Agent System) и контуром модерации человеком (Human-in-the-loop).

Система самостоятельно ищет тренды, генерирует уникальный текстовый и графический контент, управляет стадиями публикации через базу данных и принимает правки из мессенджера.

---

## 🛠 Технологический стек
* **Оркестрация процессов:** n8n (Advanced Workflow Automation)
* **База данных и Бэкенд:** Supabase / PostgreSQL (State & Content Management)
* **Языковые модели (LLM):** GPT-4o-mini / Gemini (через OpenRouter)
* **Генерация изображений:** Replicate API (модель Imagen-4 / Flux)
* **Поиск информации:** Tavily API (ИИ-поиск в реальном времени)
* **Интерфейсы и API:** VK API, Webhooks, Callbacks

---

## 📐 Архитектура и Логика работы

### 1. Исследование и Анализ (Research Phase)
* Система запускается по триггеру и опрашивает БД Supabase, чтобы подтянуть историю ранее опубликованных тем во избежание дублирования.
* ИИ-агент формулирует поисковые запросы и через **Tavily API** собирает актуальную информацию и тренды из открытых источников в сети.

### 2. Генерация Контента (Generation Phase)
* Собранное сырье передается в LLM, которая генерирует посты сразу в **трех разных контент-стилях**.
* Параллельно формируется промпт для генерации обложки. Через **Replicate API** создается уникальное изображение высокого разрешения, адаптированное под формат соцсети.
* Данные со статусом `pending` (ожидает проверки) и уникальным `batch_id` записываются в Supabase.

### 3. Контур модерации (Human-in-the-loop)
* Готовый пакет (текст + картинка) отправляется администратору через VK/Telegram с помощью интерактивных **Inline-кнопок** (*Одобрить / Отклонить / Редактировать*).
* **Кнопка «Одобрить»:** Меняет статус в БД на `approve` и автоматически отправляет пост в публикацию через VK API.
* **Кнопка «Редактировать»:** Принимает текстовый ответ от админа с правками (например: *"сделай покороче и добавь призыв к действию"*), перезапускает ИИ-агента для локального рерайта текста и обновляет карточку поста.

## 📊 Структура базы данных (Supabase)
Система использует реляционную структуру для контроля состояний:
* `posts` — хранение сгенерированного текста, ссылок на медиафайлы, `batch_id` и текущего статуса (`pending`, `approved`, `editing`).
* `history_topics` — лог задействованных тем для предотвращения повторений в контенте.

---

## 🚀 Как запустить проект локально
1. Установите и запустите **n8n** (локально или в облаке).
2. Создайте базу данных в **Supabase** и накатите таблицы (схему структуры можно найти в описании проекта).
3. Импортируйте файл `workflow.json` из данного репозитория в ваш n8n.
4. Настройте переменные окружения и учетные данные (Credentials) для OpenRouter, Replicate, Tavily и VK.
